## Key RTL Features

### Text Flow

- **LTR**: Text flows →
- **RTL**: النص يتدفق ←

### Icons

- **LTR**: [Icon] Text
- **RTL**: Text [Icon]

### Buttons

- **LTR**: [Cancel] [Accept]
- **RTL**: [Accept] [Cancel]

### Progress

- **LTR**: Step 1 → Step 2
- **RTL**: Step 2 ← Step 1

### Navigation

- **LTR**: [← Back] [Next →]
- **RTL**: [التالي ←] [رجوع →]

### Form Labels

- **LTR**: Left-aligned labels
- **RTL**: Right-aligned labels محاذ لليمين

### Checkmarks

- **LTR**: Text ✓
- **RTL**: ✓ Text

---

All these layout changes happen automatically based on the detected language (Arabic = RTL, English = LTR) using the `isRTL` variable.
